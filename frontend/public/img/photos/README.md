# School photographs

Drop real photographs into this folder. They are served at `/img/photos/<filename>`.

Suggested naming (kebab-case, descriptive):

- `campus-aerial.jpg` — wide campus shots
- `classroom-science.jpg`, `classroom-english.jpg`
- `sports-rugby.jpg`, `sports-athletics.jpg`, `sports-netball.jpg`
- `arts-choir.jpg`, `arts-drama.jpg`
- `boarding-house-a.jpg`
- `headmaster-portrait.jpg` (portrait orientation)
- `leadership-*.jpg`

Guidelines:
- Landscape photos: at least 1600 px wide, JPG/WebP, under 400 kB each
- Portraits: 1200 × 1600 px
- Only use photographs you have permission to publish
